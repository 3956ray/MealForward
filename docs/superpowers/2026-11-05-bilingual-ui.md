# 留膳：全站中文 / English

## 实现

原 product-v2 入口导航增加 Lucide Languages 图标与原生下拉选择。默认中文，localStorage `mf-language` 保存 zh/en；跨标签页同步，禁用存储时仍可在当前页面切换。设置 document.lang 与标题，数字/日期跟随语言；统计日期仍为北京时间。

词库 messages-en.json 覆盖当前应用：首页、厨房目录、善意足迹、支持与恢复、钱包登录、餐券及短码、商家登记、草稿发布、厨房设置、交餐、结算、停业及退款。共享 locale.mjs / locale-react.jsx 在展示层订阅，不重载路由，不以语言作为组件 key，不重发业务。系统错误在展示时翻译；未知错误保留代码并提供通用说明。

商家输入的名称、描述、公告、历史订单承诺原样显示，不调用机器翻译。签名正文、协议字段、金额、时段、领取资格、合约和180秒规则不变。第三方钱包本身的界面语言由钱包控制；已有 thirdweb 适配源代码同步语言，但功能仍关闭，不增加依赖或收费服务。冻结的旧演示/验收工具不是当前托管应用，不改写其界面。
